# /hudcolor

## Syntax

<!--cmd-syntax-start-->
```eqcommand
/hudcolor list | <name> <color name>
```
<!--cmd-syntax-end-->

## Description

<!--cmd-desc-start-->
Lists preset colors, and will change HUD to any of the preset colors
<!--cmd-desc-end-->

## Options

| Option | Description |
|--------|-------------|
| `<name> <color name>` | Change specified HUD to preset color (red, yellow, green, darkgreen, blue, lightblue, purple, lightgrey, darkgrey) |
| `list` | Returns: red, yellow, green, darkgreen, blue, lightblue, purple, lightgrey, darkgrey |
